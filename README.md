# Сатурн — прототип 10, Тип 4

**При сумме товаров акции от 1000 ₽ — один бесплатный подарок на выбор из трёх. Акция не кратная. При 2000, 3000, 10 000 ₽ и любых больших суммах больше одного подарка не выдаётся.**

Публичный адрес: https://kate854.github.io/10/ . Исходники — `main`, сайт — `gh-pages`.

## Локальный запуск

```sh
npm install
npm run dev
```

- `npm test` — 28 тестов логики и лимита подарков.
- `npm run build` — TypeScript и production-сборка.
- `npm run preview` — просмотр production-сборки.
- `app/index.html` — точка входа исходного React-приложения.
- `prototype.html` — готовый автономный HTML для скачивания и открытия без сервера. React, изображения SVG, CSS и логика встроены.
- Корневой `index.html` и `docs/index.html` — идентичные копии той же сборки для публикации. После сборки обновляйте все три файла из `dist/index.html` и публикацию ветки `gh-pages`.

## Сценарий

1. Начальная сумма товаров акции 555 ₽. До подарка не хватает 445 ₽.
2. Открыть «Добавить товары»: 444 ₽ дают 999 ₽, подтверждение недоступно. Товар за 700 ₽ даёт 1255 ₽ и активирует подтверждение. Изменения до подтверждения — только черновик.
3. После подтверждения шапка показывает зелёные иконки и «Отлично! Вы получаете подарок». Вместо предложения докупить — «Выбрать подарок». Второй подарок не предлагается.
4. В поп-апе три варианта и «Доступно: 1 подарок». До выбора подтверждение недоступно.
5. Выбрать один вариант: кнопка «Добавлено», альтернативы бледные и недоступны, подтверждение красное. Подарок ещё не применён до подтверждения.
6. Подтвердить: в корзине одна бесплатная подарочная строка, в шапке «Изменить подарок».
7. Увеличить количество платных товаров: подарочная квота по-прежнему один. Повторный выбор того же или другого подарка сверх квоты заблокирован, отдельного счётчика увеличения подарка нет.
8. Для замены нажать «Изменить подарок», снять текущий выбор кнопкой «Добавлено», выбрать другой вариант и подтвердить. Отмена, крестик, Escape и клик снаружи сохраняют прежний выбор.

Если сумма товаров акции опустится ниже 1000 ₽, подарок и память удалённого подарка исчезают. При повторном достижении порога снова можно выбрать ровно один подарок.

## Варианты подарка

- Лента армирующая Knauf Курт 50 мм x 25 м — комплектация «4 рул.».
- Лента уплотнительная Knauf Дихтунгсбанд, 0,03x30 м — «2 рул.».
- Штукатурка Церезит CT 64 короед 2,0 мм база, 25 кг — «1 шт.».

Каждый вариант считается одним подарком/комплектом, как на макетах. Подписи комплектации не увеличивают число подарочных мест. Подарок бесплатный и не входит в сумму акции.

## Удаление — как в последней итерации №99

Корзина справа полностью убирает подарочную строку. Под подарочным списком появляется **«Удалено: 1 подарок»** и **«Вернуть подарки»**. Кнопка немедленно восстанавливает тот же вариант без поп-апа. Сумма заказа не меняется. Сообщение в шапку не переносится, пустая карточка удалённого подарка не сохраняется. Если вместо восстановления подтвердить другой вариант, память удаления очищается.

## Проверено

28 тестов: включительный порог 1000 ₽, 999,99 ₽, большие суммы с жёстким лимитом 1, сумма с количеством в копейках, три варианта, невозможность второго выбора даже с завышенной входной квотой, замена, отмена, объединение платных позиций, удаление и возврат.

В Chromium пройдены все восемь визуальных состояний, выбор каждого варианта, изменение подарка, проверка одной подарочной строки при 5000+ ₽, удаление и прямой возврат, четыре способа закрытия, фокус, потеря/возврат права на подарок, мобильный экран и автономность HTML. Ошибок JavaScript нет.

## Дизайн и демонстрационные данные

React + TypeScript + Vite, без backend. Верстка по вложенным макетам; изображения упаковок, лент и знак логотипа — локальные SVG-иллюстрации. Макеты целиком не используются как интерфейс.

По главным условиям пользователя реализована именно акция «от 1000 ₽», несмотря на оставшиеся подписи «за каждые 1000» в отдельных вспомогательных кадрах. В коде и интерфейсе условий кратности нет.

Общий итог на макетах не совпадает с суммой цен строк. Как в предыдущих прототипах, используются реальные суммы отображённых цен. В порог входят только акционные товары. Услуги, скидка по карте и бонусы — демонстрационные данные макета.
